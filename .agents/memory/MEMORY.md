- [Raw PDF/file download routes](raw-download-routes.md) — Express routes for binary file downloads intentionally live outside the OpenAPI spec; frontend hits them directly via `window.open`.
- [Gold-shop seeded admin login](gold-shop-admin-login.md) — seed script's default admin (0000000000/1234) only applies on empty DB; check `users` table for real credentials before e2e testing.
- [Gold-shop gold rate scraper](gold-shop-gold-rate-scraper.md) — free Yahoo Finance JSON API (`/v8/finance/chart/GC=F`) replaces all paid APIs; in-memory cache + 5-min setInterval; writes back to DB on each successful scrape.
- [Gold-shop invoice price-locking](gold-shop-price-locking.md) — invoices/invoice_items are frozen numeric snapshots (metalRate, unitPrice, purityMultiplier) written once at creation; no update route exists, and detail/PDF views must only ever read stored fields, never live prices.
- [Gold-shop mobile responsive patterns](gold-shop-mobile-responsive.md) — print-fidelity documents (invoice PDF) stay fixed-width in their own overflow-x-auto wrapper rather than being reflowed; other pages use standard Tailwind stacking.
- [Gold-shop core asset parity](gold-shop-asset-parity.md) — new metal/karat rate types must get full manual-editable/live-syncable parity (DB column, API, OpenAPI, AssetCard, invoice lookup) like existing assets, not a derived/read-only shortcut.
- [Gold-shop public routes pattern](gold-shop-public-routes.md) — unauthenticated pages (e.g. showroom display board) need both a public API sub-router mounted before `requireAuth` and a wouter route matched before the AuthGate.
- [Gold-shop per-item live rate injection](gold-shop-per-item-live-rate.md) — each invoice row derives its own metal rate from live prices; never reintroduce a single shared page-level rate driving heterogeneous rows.
- [Gold-shop pricing engine (spot-based)](gold-shop-pricing-engine.md) — Base_24K derived from XAU/USD international spot + admin spread/labor%; API server needs a workflow restart to pick up backend route changes (no hot reload).
- [Gold-shop TV board price_items system](gold-shop-tv-board-price-items.md) — TV board rows driven by `price_items` DB table; frontend computes prices via `computeItemPrice(item, baseAedPerGram)` in showroom-board.tsx; live-price context no longer exposes raw* precomputed fields.
- [UAE Kilo Bar 995 convention](uae-kilo-bar-995-convention.md) — 995 kilo bar uses 23/24 purity factor (not 0.995); Dubai showroom convention matching livepriceofgold.com reference app.
